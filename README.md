# ASHLINE

Browser arena first-person shooter site with a playable demo.

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Production server

```bash
npm run build
npm start
```

Serves `dist/` on `http://127.0.0.1:3000` (`HOST` / `PORT` env vars supported).

## Controls

- Click arena to lock pointer
- WASD — move
- Mouse — look
- Left click — fire
- R — reload
